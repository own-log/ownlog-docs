# OwnLog 문서

멀티유저 블로그 플랫폼 **OwnLog(온로그)** 의 기획·설계·운영 문서를 모아 둔 저장소예요.

- 서비스: https://ownlog.java21.net
- 소스 코드: https://github.com/AIP-1/blog-basic-AIGJ_01_007-firstblog

## 왜 저장소를 나눴나요
코드 저장소는 `main`에 푸시하면 자동으로 배포돼요. 문서가 같은 저장소에 있으면 문서만 고쳐도 배포가 돌 수 있어요(문서와 함께 바뀐 점검 스크립트, 코드와 한 릴리스로 묶인 문서 수정). 그래서 문서는 이 저장소에서 따로 관리하고, 고쳐도 배포에 영향이 없게 했어요.

- 코드의 동작이 바뀌는 문서(요구사항, ERD, API 명세)는 코드 작업과 같은 날 함께 고쳐요. 커밋 메시지에 코드 저장소의 브랜치나 커밋을 적어요.
- 이 저장소는 `main` 하나만 써요. 배포가 없어서 바로 커밋해도 돼요.
- 이력은 코드 저장소에서 문서가 바뀐 커밋을 그대로 옮겨 왔어요 (`git log`로 볼 수 있어요).
